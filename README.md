# Group 8 parking entrance study

Start with [the study README](Group8_Parking_Booth_Simulation/README.md) for uv
setup, notebook execution, and verification. The model assumes guards sharing
one reader and uses documented estimated inputs.

- [Revised proposal](<Modeling Proposal.md>) explains the question, assumptions,
  and changes from the submitted proposal.
- [Submitted proposal](materials/Modeling_Proposal.pdf) remains the submission record.
- [Terminology](CONTEXT.md) distinguishes booths, guards, readers, and measures.
- [Branch progress](branch-progress-report.md) records what passed and what remains.
- [Notebook](Group8_Parking_Booth_Simulation/Parking_Booth_Simulation.ipynb) runs
  the experiments and exports tables, figures, and a conditional interpretation.

Instructor acceptance of the revision and field validation are not established.
