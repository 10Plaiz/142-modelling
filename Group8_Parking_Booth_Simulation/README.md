## Run it
```bash
pip install simpy numpy scipy pandas matplotlib jupyter
jupyter notebook Parking_Booth_Simulation.ipynb    # then Kernel > Restart & Run All
python parking_sim.py                              # quick 30-replication baseline, no notebook
```

A full run takes under a minute. Tested with Python 3.12 and SimPy 4.1.2; the code also runs on Python 3.10+.

## Replacing placeholder data with field observations
| File | Columns | How to collect |
|---|---|---|
| `gate_entry_log.csv` | `vehicle_no, entry_timestamp` (HH:MM:SS) | Main gate entry log for one full high-traffic day, 07:00–19:00. |
| `service_times.csv` | `obs_no, window` (`peak`/`offpeak`), `service_sec` | Stopwatch from the vehicle stopping at the booth to the barrier lifting. 30 in 07:00–09:00, 30 off-peak. |
| `site_measurements.csv` | `approach_length_m, avg_vehicle_length_m, avg_gap_m, measured_on` | Measure gate to road edge. **Set `measured_on` to the date**: the notebook treats the value `PLACEHOLDER` as a flag. |
| `peak_arrival_tally.csv` | `interval_start, arrivals_tallied` | **Strongly recommended.** One member stands at the tail of the queue 07:00–09:00 and counts vehicles *joining* the line per 15 min. Filled rows override the gate log for those intervals. |
| `validation_observations.csv` | `snapshot_time, queue_length_observed` | Every 5 min, 07:05–09:00, count vehicles waiting (excluding the one at the booth). Use a **different day** from the arrival data if possible. Used only for validation, never for fitting. |

**Why the tally matters:** the gate log timestamps when a vehicle *passes the booth*. While a queue exists, passages are capped at booth capacity (about 30 per 15 min), so the log can never show peak demand above that. It under-counts exactly the congestion the study is about.

Also note whether any vehicles are already waiting at 07:00; the model assumes none.

## Results files
| File | Contents |
|---|---|
| `arrival_rates_and_load.csv` | Counts, rates, and ρ per 15-min interval for 1 and 2 booths |
| `input_fit_summary.csv` | Chi-square, KS, and AIC for exponential / lognormal / triangular fits |
| `verification_checks.csv` | 11 checks: hand trace, D/D/1, conservation, sanity, FIFO, Little's law, booth closing, CRN, M/M/1, M/M/2 |
| `replications_raw.csv` | Every measure for every replication and configuration |
| `summary_by_config.csv` | Mean, SD, SE, and 95% CI per measure per configuration |
| `paired_differences.csv` | Paired-t CIs on (1 booth − 2 booths) with the CRN variance reduction |
| `spillover_probability.csv` | Monte Carlo estimate of P(a high-traffic day has spillover), Wilson CI |
| `queue_profile_by_interval.csv` | Mean and 5th/95th-percentile queue length per 15 min |
| `fluid_step_size.csv` | Euler vs RK4 error at 08:00 for halving step sizes (continuous model) |
| `fluid_vs_des.csv` | Queue per 15 min: stochastic fluid, deterministic fluid, and DES mean; plotted in `figures/fluid_cross_check.png` |
| `replication_planning.csv`, `replication_followup.csv` | Week 7 replications-needed calculation and follow-up runs until targets are met |
| `validation_comparison.csv` | Model prediction bands at the snapshot times (plus observed values once collected) |
| `extreme_conditions.csv` | Near-zero and ×1.5 traffic face-validity runs |
| `sensitivity_arrival_service.csv`, `sensitivity_distribution.csv`, `sensitivity_K.csv` | Robustness of the recommendation |
| `evidence_summary.csv` | The five kinds of evidence a credible study reports |
