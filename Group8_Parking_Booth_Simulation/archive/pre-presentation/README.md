# Historical exports

These files preserve the generated results and figures that were present before
the presentation-ready notebook run. They belong to the earlier study and may
describe independent booths or analyses not run in the current revision.

Use the project-level `results/`, `figures/`, and `presentation/` for current
evidence. Do not combine their values with this archive.

The archive retains the first copy of each previous export. Original inputs and
model source were not moved here. Each later verification run has its own full
evidence copy under the repository's ignored `artifacts/notebook-verification/`.
